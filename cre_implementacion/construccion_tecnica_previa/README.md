# Construcción técnica previa

Archivo histórico de artefactos reemplazados o no requeridos por el despliegue consolidado.

- `implementacion_por_entidad/`: jobs individuales, JSON duplicados, documentación y scripts por tabla.
- `templates_ingenieria_original/`: plantillas iniciales Silver/Gold/ingesta y automatizaciones anteriores.
- `prototipos_databricks/`: primeros notebooks de creación/carga desde archivos.

Estos archivos se preservan para trazabilidad. No deben incluirse en despliegues ni ejecutarse junto con el pipeline de `pre_productiva/`.
